# Jellyflix demo

To run it locally, use `npm ci`, `npm run build`, and `npm run dev` from the project root. Open [the local preview](http://127.0.0.1:4173/).

Add `?layout=desktop` before the hash to preview desktop mode, for example [desktop Home](http://127.0.0.1:4173/?layout=desktop&featured=0#/home).
