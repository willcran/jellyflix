# Jellyflix

A cinematic interface for Jellyfin.

This fork keeps the compatible Jellyfin plugin identity and saved Home/configuration data stable while presenting the project as Jellyflix.

## Install

In Jellyfin, add this repository:

```text
https://raw.githubusercontent.com/willcran/jellyflix/main/manifest.json
```

Then install Jellyflix and restart Jellyfin.

## Build

```sh
npm ci
npm run build
```

## Use

Use Jellyfin Web in Desktop or TV display mode. Jellyflix activates automatically there.
